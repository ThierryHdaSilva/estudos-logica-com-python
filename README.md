# Estudos de Lógica de Programação com Python

Este repositório reúne exercícios práticos para estudar lógica de programação utilizando Python.

Os exemplos abordam:

- Variáveis e tipos de dados;
- Entrada e saída de informações;
- Operadores matemáticos;
- Estruturas condicionais;
- Estruturas de repetição;
- Listas, tuplas e dicionários;
- Funções;
- Módulos e bibliotecas;
- Manipulação de arquivos;
- Matrizes e algoritmos;
- Validação de dados.

## Pré-requisitos

Para executar os exercícios, é necessário ter:

- Python 3 instalado;
- Git instalado, caso queira clonar o projeto.

O exercício `ex037.py` utiliza a biblioteca `requests`. Para executá-lo, instale a dependência com:

```bash
pip install requests
```

## Como baixar o projeto

Clone o repositório utilizando o comando:

```bash
git clone https://github.com/thierryHdaSilvaAux00/estudos-logica-com-python.git
```

Depois, entre na pasta do projeto:

```bash
cd estudos-logica-com-python
```

## Estrutura do projeto

Os exercícios estão organizados nos seguintes diretórios:

```text
estudos-logica-com-python/
├── code-atividades/
├── code-atividades-2/
├── GUIA_ATIVIDADES.md
└── README.md
```

A pasta `code-atividades/` contém os exercícios iniciais de lógica, estruturas de dados, funções, módulos e arquivos.

A pasta `code-atividades-2/` contém desafios mais completos, como palíndromos, matrizes, cifra de César, controle de estoque e validação de senhas.

## Como executar os exercícios

Os scripts devem ser executados a partir da pasta principal do projeto.

Para executar um exercício da pasta `code-atividades/`, utilize:

```bash
python code-atividades/ex001.py
```

Para executar um exercício da pasta `code-atividades-2/`, utilize:

```bash
python code-atividades-2/ex049.py
```

No Windows, também é possível utilizar o comando `py`:

```bash
py code-atividades/ex001.py
py code-atividades-2/ex049.py
```

Alguns exercícios solicitam informações pelo terminal durante a execução. Nesse caso, digite os valores solicitados e pressione `Enter`.

## Exemplos de execução

### Calculadora de áreas

O arquivo `main.py` apresenta um menu para calcular a área de um círculo, triângulo ou retângulo:

```bash
python code-atividades/main.py
```

### Escrita e leitura de arquivos

O arquivo `ex040.py` grava uma saudação em um arquivo de texto:

```bash
python code-atividades/ex040.py
```

Depois, execute o arquivo `041.py` para ler a saudação gravada:

```bash
python code-atividades/041.py
```

O arquivo `041.py` depende da execução anterior do `ex040.py`.

### Exercícios da segunda etapa

Para executar um desafio da pasta `code-atividades-2/`, por exemplo:

```bash
python code-atividades-2/ex058.py
```

Esse exercício executa uma cifra de César e solicita uma mensagem e um deslocamento.

## Objetivo

O objetivo deste repositório é praticar os fundamentos da programação e desenvolver a capacidade de resolver problemas utilizando Python.

Este material pode ser utilizado por pessoas que estão iniciando seus estudos em programação ou revisando conceitos fundamentais da linguagem.
